## 1. الملخص التنفيذي (Executive Summary)

**SENAM** منصة رقمية تجمع شركات الخدمات تحت مظلة واحدة، تتيح للعميل اكتشاف الشركة المناسبة، مقارنة الأسعار والتقييمات، حجز الخدمة، تتبع تنفيذها، والدفع إلكترونياً من خلال تجربة سلسة وفخمة.

تنطلق المنصة في مرحلتها الأولى بقطاع **غسيل السيارات** كقطاع رئيسي (Vertical-first)، مع بنية تقنية مرنة قابلة للتوسع لقطاعات متعددة (حلاقة، تنظيف منزلي، صيانة، كهرباء، سباكة، تأجير سيارات، مشاريع منزلية).

### 1.1 الرؤية
أن تكون SENAM المنصة الأولى الموثوقة لحجز الخدمات في قطر والخليج، بمعايير جودة وفخامة لا مثيل لها.

### 1.2 الرسالة
تمكين العميل من الوصول لأفضل الخدمات في مكانه وبسعر عادل، وتمكين الشركات الصغيرة والمتوسطة من الوصول لقاعدة عملاء أوسع.

### 1.3 القيم الأساسية
- الثقة والشفافية
- جودة معتمدة
- سرعة الإنجاز
- تجربة فخمة

## 3. الفئات المستهدفة (User Personas)

### 3.1 العميل (Customer)
**أحمد – 32 سنة – موظف في الدوحة**
- يملك سيارة فاخرة ويحرص على نظافتها أسبوعياً
- وقته ضيق، يبحث عن خدمات تصل لباب البيت أو العمل
- يفضل الدفع الإلكتروني
- حساس للجودة أكثر من السعر
- يستخدم تطبيقات: طلبات، كريم، Snoonu

**احتياجاته:**
- شركات موثوقة لا يحتاج للبحث عنها كل مرة
- وقت محدد بدقة بدون انتظار
- شفافية في السعر والخدمة
- إمكانية إعادة الطلب بسرعة

### 3.2 صاحب الشركة (Service Provider)
**خالد – صاحب شركة غسيل سيارات متنقل (5 موظفين)**
- يعتمد على التسويق التقليدي (WhatsApp + Word of mouth)
- يعاني من جدولة المواعيد يدوياً
- يفقد عملاء بسبب عدم وجود نظام إدارة

**احتياجاته:**
- مصدر دائم للطلبات
- نظام بسيط لاستقبال وإدارة الطلبات
- تقارير مالية واضحة
- بناء سمعة رقمية عبر التقييمات

### 3.3 المسؤول (Admin)
**فريق إدارة SENAM**
- مراقبة جودة الخدمات
- إدارة العمولات والمدفوعات
- حل النزاعات
- استخراج التقارير

## 4. نطاق المنتج (Scope)

### 4.1 ضمن نطاق MVP (In-Scope)
- تطبيق العميل (iOS + Android) بـ Flutter
- لوحة تحكم الشركات (Web Responsive)
- لوحة تحكم الإدارة (Web)
- قطاع غسيل السيارات فقط في الإطلاق
- مدينة الدوحة فقط جغرافياً
- اللغة العربية فقط

### 4.2 خارج نطاق MVP (Out-of-Scope)
- تطبيق Native iOS/Android منفصل للشركات (لوحة Web تكفي مبدئياً)
- القطاعات الأخرى (تأتي في v2)
- التوسع الجغرافي خارج الدوحة
- اللغة الإنجليزية
- نظام الاشتراكات الشهرية
- نظام Loyalty Points
- المتجر داخل التطبيق (E-commerce)

## 7. متطلبات لوحة تحكم الشركات (Provider Dashboard)

### 7.1 الميزات الأساسية
- **Dashboard:** الطلبات الحالية، الإيرادات اليومية/الشهرية، التقييمات
- **الطلبات الجديدة:** Notifications فورية + قبول/رفض خلال زمن محدد (مثلاً 5 دقائق)
- **إدارة الطلبات النشطة:** تحديث الحالة (في الطريق، وصل، جاري التنفيذ، اكتمل)
- **التقويم:** عرض المواعيد المحجوزة وإدارة التوافر
- **إدارة الخدمات:** عرض الخدمات والأسعار المسموح بها
- **إدارة الفنيين:** إضافة الموظفين وإسناد الطلبات لهم
- **التقارير المالية:** الإيرادات، العمولات المستحقة، صافي الربح
- **التقييمات:** عرض تقييمات العملاء والرد عليها
- **الملف الشخصي للشركة:** تعديل البيانات، الصور، ساعات العمل
- **الإعدادات:** الإشعارات، طرق الدفع، الحساب البنكي

## 8. تدفقات المستخدم الرئيسية (User Flows)

### 8.1 تدفق التسجيل
```
فتح التطبيق → Splash → Onboarding (3 شاشات) → إدخال رقم الجوال
 → استلام OTP → التحقق → إكمال الملف (الاسم) → تحديد الموقع → الرئيسية
```

### 8.2 تدفق الحجز
```
الرئيسية → اختيار قسم → قائمة الشركات → فلترة/بحث → تفاصيل الشركة
 → اختيار خدمة → اختيار التاريخ والوقت → تحديد الموقع → ملخص الطلب
 → اختيار طريقة الدفع → تطبيق كوبون (اختياري) → تأكيد الطلب → شاشة النجاح
```

### 8.3 تدفق التتبع
```
طلباتي → اختيار الطلب الحالي → شاشة التتبع
 → تحديثات Push للحالات → وصول الفني → اكتمال الخدمة → شاشة التقييم
```

### 8.4 تدفق الإلغاء
```
طلباتي → الطلب → زر إلغاء → سبب الإلغاء → تأكيد
 → فحص السياسة (إذا قبل قبول الشركة = مجاني | بعد القبول = رسوم 10 ريال)
 → استرجاع المبلغ (إذا دفع إلكتروني) → إشعار للعميل والشركة
```

### 8.5 تدفق الشكاوى
```
الطلب المكتمل → "لدي شكوى" → نوع الشكوى → الوصف + صور
 → إرسال للأدمن → فتح Ticket → التحقيق (24-48 ساعة)
 → القرار (استرجاع جزئي/كامل/رفض) → إشعار للعميل
```

## 9. القواعد التجارية (Business Rules)

### 9.1 العمولات
- العمولة الافتراضية: **15%** من قيمة الطلب
- العمولة قابلة للتعديل لكل شركة (10% - 25%)
- الشركات الذهبية (Premium): عمولة مخفضة + ظهور مميز

### 9.2 سياسة الدفع
- تحصيل المبلغ كاملاً عند تأكيد الطلب (إلكترونياً)
- الدفع النقدي يخصم العمولة من الشركة لاحقاً
- التسوية مع الشركات أسبوعياً (كل يوم أحد)

### 9.3 سياسة الإلغاء
| التوقيت | الرسوم |
|---|---|
| قبل قبول الشركة | مجاني، استرجاع كامل |
| بعد القبول، قبل خروج الفني | 10 ر.ق رسوم خدمة |
| بعد خروج الفني | 50% من قيمة الطلب |
| بعد بدء العمل | لا يوجد استرجاع |

### 9.4 سياسة قبول الطلبات للشركة
- يجب على الشركة قبول أو رفض الطلب خلال **5 دقائق**
- بعد 5 دقائق يتم تحويل الطلب لشركة أخرى تلقائياً
- معدل الرفض المرتفع (>20%) يؤثر على ترتيب الشركة

### 9.5 سياسة التقييمات
- لا يمكن تقييم الخدمة قبل اكتمالها
- التقييم نهائي بعد 48 ساعة (لا يمكن تعديله)
- الشركة تستطيع الرد على التقييم مرة واحدة

### 9.6 الانضمام للشركات (KYC)
**المستندات المطلوبة:**
- السجل التجاري
- البطاقة الضريبية
- صورة المالك (هوية شخصية)
- صور من مقر الشركة
- شهادات الفنيين (إن وجدت)
- التأمين على المنشأة

### 9.7 محفظة الفنيين
- كل فني له ملف مع تقييم وعدد طلبات منجزة
- يمكن للعميل اختيار "نفس الفني السابق" عند إعادة الطلب

## 10. المتطلبات التقنية (Technical Requirements)

### 10.1 Stack المقترح
| الطبقة | التقنية |
|---|---|
| تطبيق العميل | Flutter 3.x + Dart |
| لوحات التحكم | React.js / Next.js |
| Backend API | Node.js (NestJS) أو Laravel |
| Database | PostgreSQL 15+ |
| Cache | Redis |
| Real-time | Socket.io / Pusher |
| Authentication | Firebase Auth (OTP) |
| Push Notifications | Firebase Cloud Messaging |
| File Storage | AWS S3 / Cloudflare R2 |
| Maps | Google Maps API / Mapbox |
| Payment Gateway | MyFatoorah / Tap Payments |
| Analytics | Mixpanel / Firebase Analytics |
| Crash Reporting | Sentry / Firebase Crashlytics |
| CI/CD | GitHub Actions / Codemagic |
| Hosting | AWS (EC2 + RDS + S3) أو Hetzner |
| CDN | Cloudflare |

### 10.2 معايير الأمان
- HTTPS إجباري على كل الـ Endpoints
- JWT للمصادقة + Refresh Tokens
- تشفير البيانات الحساسة (AES-256)
- حماية من SQL Injection / XSS / CSRF
- Rate Limiting على APIs
- 2FA للوحات التحكم
- النسخ الاحتياطي اليومي (Database)
- التوافق مع PCI-DSS لبيانات الدفع

### 10.3 الـ APIs المطلوبة
- Authentication APIs (OTP, Login, Logout, Refresh)
- User APIs (Profile, Addresses, Favorites)
- Categories & Services APIs
- Companies APIs (List, Details, Search, Filter)
- Booking APIs (Create, Update, Cancel, Track)
- Payment APIs (Charge, Refund, Wallet)
- Reviews APIs
